# Qualify the complete owner trial: sibling delivery plan

Owner-authorized backlog creation on November 1, 2026. **Application implementation is not authorized.** This plan supplies source scope/intent for intake; native refinement, implementation planning and approval remain later gates.

## Scope

Record independent Mac/iPhone/iPad evidence for all eleven cases against one identified deployed application release.

Root-level sibling epic only. Children deliver to this epic branch; all children complete → integrated epic Test/Review → trunk → same-SHA Cloudflare deployment and local Mac build → owner tests both. One orchestrator; at most three workers globally. No nested epic or outer integration branch.

## Technical lineage

Reviewed source Task(s) 10; acceptance 1–11 in `docs/superpowers/plans/2026-11-01-first-usable-project-estimator.md`; trial specification acceptance cases 1–11 only. The reviewed files remain unchanged. Preserve all owner recipe/prices/settings/origin checkpoints and deferred-feature boundaries. Synthetic fixtures remain draft/test-only.

## Prerequisites and ownership

Prerequisite sibling keys: office-recovery, app-upgrades, field-recovery, catalog-refresh. Cross-epic dependencies mean completed code on trunk.

All 13 stories are nonparallel: one owner and shared production catalog/application releases require coordinated sessions. Story 1 pins already-deployed conformance actions and introduces no app functionality. Both device baselines close before rotation; both rotation sessions close before upgrades. Stage the iPad old-version state before the shared 1.0.1 publication used by stories 7 and 8; completing phone evidence never proves tablet behavior. Sharing follows upgrades, isolated recovery follows returns, and final ledger reconciliation follows all observations.

A shared schema/export/store migration/HTTP route/App composition/lockfile has one designated owner. Consumers use the accepted epic-head contract and disjoint files. Partial renderer preparation is not a complete parallel-ready story when its producer is still missing. No gate/Full-Auto preference is changed.
